# M2: Local API, Events and Remote Access Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The engine serves its data over a local HTTP API with a live event stream. This PC reaches it with the launch password, and the laptop reaches it through Tailscale with a paired device key.

**Architecture:**
- A FastAPI app (`engine/api.py`) runs inside the engine process. uvicorn serves it on 127.0.0.1:47615, from a thread of its own.
  - Spec section 3 says "the main asyncio loop", but M1 keeps the main thread for Ctrl+C: on Windows a blocking wait ignores Ctrl+C (see M1's Task 9 rulings).
  - Off the main thread, uvicorn installs no signal handlers, so the engine stops it.
- Each request opens its own SQLite connection. Live updates come from the engine's existing `EventBus`, through FastAPI's built-in Server-Sent Events.
- Remote devices go through `tailscale serve` on the PC. They prove themselves with a device key, which comes from a one-time pairing code that `assistant pair` shows.

**Tech Stack:**
- **Python:** FastAPI 0.162, Starlette ≥ 1.9, uvicorn 0.54, httpx2 (the test client), SQLite.
- **Node:** openapi-typescript 7.13.0 with TypeScript 5, for the front end's types.
- **Remote access:** Tailscale `serve`.

**Spec:** `docs/superpowers/specs/2026-10-25-desktop-app-redesign-design.md`. The sections that matter are A4, A6, A8, section 3 "Two computers", section 5, section 8 (v8), section 9 and section 11.

**Builds on:** M1 (`docs/superpowers/plans/2026-10-25-m1-engine-core.md`). Its decisions are in `docs/superpowers/plans/2026-10-25-m1-engine-core-rulings.md`.

## Global Constraints

- **Pinned versions** (checked on 2026-10-27):

  | Package | Pin | Note |
  |---|---|---|
  | `fastapi` | `>=0.162,<1` | |
  | `starlette` | `>=1.9` | 1.9 is the first TestClient that streams; earlier ones hang on an endless event stream |
  | `uvicorn` | `>=0.54,<1` | Plain, not `[standard]`: uvloop doesn't run on Windows |
  | `httpx2` | `>=2.16` | Dev only. Starlette's TestClient prefers it, and anthropic already installs it. |
  | `openapi-typescript` | `7.13.0` (exact) | |
  | `typescript` | `5.x` (exact pin) | |

- **The API listens only on 127.0.0.1**, on `[api] port` (default **47615**). Other devices reach it only through `tailscale serve --bg 47615` on the PC.
- **Credentials:** `Authorization: Bearer <secret>`.
  - The **launch password** is `secrets.token_urlsafe(32)`, new at each launch. It is accepted only when the Host is `127.0.0.1:<port>`.
  - A **device key** is `secrets.token_urlsafe(32)`. Only its SHA-256 hex digest is stored.
  - Secrets are compared with `hmac.compare_digest` on bytes.
  - Every route needs one, except `GET /api/health` and `POST /api/pair`.
- **Pairing codes:** 6 digits, valid **5 minutes**, single use, void after **5** wrong tries.
- **Host header** must be exactly `127.0.0.1:<port>` or `[api] tailnet_host`. Anything else gets **400 "Invalid host header"**.
- **Tailscale identity:** when `[api] tailnet_login` is set, a request that carries `Tailscale-User-Login` must match it (compared case-insensitively), or it gets 403.
- **CORS:** allow exactly `http://tauri.localhost` (Tauri 2's default webview origin on Windows), plus `http://localhost:5173` only with `assistant engine --dev`. No trailing slashes.
- **Never sent and never logged:** responses never include `body_text` or a sender's email address (display names only). No key, password or pairing code is ever logged.
- **uvicorn:** `uvicorn.Config(app, host="127.0.0.1", port=..., log_config=None, timeout_graceful_shutdown=2)`. `log_config=None` because the engine owns logging; without the timeout, an open event stream blocks shutdown forever.
- **"Today" and "this week" use the Asia/Ho_Chi_Minh day** (`costs.TIMEZONE`).
- **"For you"** = `status = 'active'`, the deadline is null or ≥ today, and `score >= [dashboard] for_you_min_score` (default **60**).
- **Gmail link:** `https://mail.google.com/mail/?authuser=<url-encoded gmail address>#all/<message_id>`.
- **Tests stay offline.** Loopback servers are allowed (`tests/conftest.py`). `TestClient` uses `base_url="http://127.0.0.1:47615"`, so the Host check passes.
- M1's rules still hold: `gmail.readonly` only; no mail bodies or keys in logs; the CLI writers refuse while the engine runs.

## Review Focus

1. **The laptop's connection drops mid-stream** (Wi-Fi switch, lid closed). The stream's task must end and unsubscribe from the `EventBus`: no leaked subscriber, no stuck thread. Test: Task 8, `test_a_dropped_event_stream_unsubscribes`.
2. **Ctrl+C while the laptop holds the event stream open.** The engine must still stop within about 3 s. Test: Task 9, `test_the_server_stops_promptly_with_a_stream_open`.
3. **A search or filter with SQL wildcard or quote characters** (`%`, `_`, `'`, `"`, `\`) is matched literally and never errors. Test: Task 5, `test_search_treats_wildcards_and_quotes_literally`.
4. **A device revoked while its event stream is open.** The stream must end within 20 s, not live on for days. Test: Task 8, `test_a_revoked_device_loses_its_open_stream`.
5. **Counts around HCMC midnight** (17:00 UTC): "new today" and "deadlines this week" follow the Ho Chi Minh day, not the UTC day. Test: Task 7, `test_today_counts_follow_the_hcmc_day`.

### Task 2: Pairing and device keys

**Files:**
- Create: `src/assistant/engine/devices.py`
- Modify: `src/assistant/cli.py` (the `pair` and `devices` commands), `src/assistant/errors.py`
- Test: `tests/test_devices.py`

**Interfaces:**
- Consumes: the `devices` table (Task 1), `Store.get_state` and `set_state`.
- Produces:
  - `errors.PairingError(AssistantError)`. Its messages are for the user and never include the code.
  - `devices.CODE_TTL = timedelta(minutes=5)`, `devices.MAX_TRIES = 5`
  - `devices.new_pairing_code(store, now_utc) -> str`
    - Six random digits (`secrets.randbelow`).
    - Stores the state keys `pairing_code_hash` (SHA-256 hex of the code), `pairing_expires_at` (ISO, UTC) and `pairing_tries` ("0").
    - A new code replaces an unused one.
  - `devices.redeem_code(store, code: str, device_name: str, now_utc) -> tuple[int, str]`
    - Returns `(device_id, key)`.
    - Raises `PairingError` when there is no code, it has expired, it is wrong, or the tries are used up. A wrong code adds a try; the fifth wrong try clears the code.
    - Success clears the code.
    - `device_name` is stripped to at most 40 printable characters, `"device"` when empty.
  - `devices.device_for_key(store, key: str, now_utc) -> int | None`
    - Looks up the SHA-256 of the key among unrevoked devices.
    - Updates `last_seen_at` when it is older than 60 s.
  - `devices.list_devices(store) -> list[sqlite3.Row]`: id, name, created_at, last_seen_at, revoked_at.
  - `devices.revoke(store, device_id: int, now_utc) -> bool`
  - **CLI** (allowed while the engine runs: none of these writes the queue or the rankings):
    - `assistant pair` prints the code, the minutes left, and the PowerShell line the laptop runs (`Invoke-RestMethod -Method Post -Uri https://<tailnet_host>/api/pair -ContentType application/json -Body '{"code":"<code>","device_name":"laptop"}'`). It says so when `[api] tailnet_host` is not set yet.
    - `assistant devices` lists devices.
    - `assistant devices revoke <id>` revokes one.

**Files:**
- Create: `src/assistant/engine/api.py`

**Interfaces:**
- Consumes: `devices.*` (Task 2), `ProfileHolder`, `EventBus` (M1), `Config.api`, `Config.dashboard` (Task 1).
- Produces:
  ```python
  @dataclass(frozen=True)
  class ApiContext:
      cfg: Config
      holder: ProfileHolder
      bus: EventBus
      launch_password: str
      stop: threading.Event
      dev: bool = False
      clock: Callable[[], datetime] = utc_now
  ```
  - `create_app(ctx: ApiContext) -> FastAPI`. The constructor touches neither the database nor the keyring, so it can also build the OpenAPI document (Task 10).
  - `Caller(kind: Literal["local", "device"], device_id: int | None)`, which the dependency `caller()` returns.
  - **Database dependency:** `store()` opens `Store(ctx.cfg.db_path)` per request and closes it afterwards.
  - **Order of checks:**
    1. **Host check:** a small ASGI middleware, exact match including the port (Starlette's TrustedHostMiddleware ignores ports).
    2. **CORS:** `CORSMiddleware` with `allow_methods=["GET", "POST", "DELETE"]` and `allow_headers=["Authorization", "Content-Type"]`.
    3. **Credentials, `caller()`:**
       - The launch password is accepted only when Host is `127.0.0.1:<port>`.
       - Otherwise a device key is required.
       - Then the Tailscale-login rule (Global Constraints) is applied.
       - A missing or wrong credential gets 401 with `WWW-Authenticate: Bearer`.
  - **Routes:**
    - `GET /api/health` → `{"ok": true, "version": "<package version>"}`
    - `POST /api/pair` with body `{"code": str, "device_name": str}` → `{"device_id": int, "key": str}`, or 400 with the `PairingError` message.
    - `GET /api/devices` and `DELETE /api/devices/{id}`. These need the `local` caller; a device gets 403.

**Interfaces:**
- Consumes: `caller()`, `store()` and `ApiContext` (Task 3); `rank.score`, `rank.explain`, `store.opportunity_from_row`.
- Produces:
  - **`GET /api/opportunities`**
    - **Query:** `tab: Literal["for_you","all","starred","applied","dismissed"] = "for_you"`, `kind: str | None`, `deadline_within: int | None` (days, 0–365), `min_score: int | None`, `q: str | None` (≤ 100 characters), `limit: int = 200` (1–1000), `offset: int = 0`.
    - **Returns** `{"tab_total": int, "total": int, "items": [OpportunityRow]}`. `tab_total` counts before the filters, so the client can show "N hidden by filters".
  - **The tabs:**
    - `for_you` follows the Global Constraints definition.
    - `all` = active and not past its deadline.
    - `starred` = `starred = 1`, any status.
    - `applied` / `dismissed` match on status.
  - **Order:** score descending; deadline ascending, with no deadline last; then `last_seen_at` descending.
  - `OpportunityRow`: `id`, `kind`, `title`, `organizer`, `deadline`, `location`, `location_scope`, `score`, `why`, `seen_count`, `starred`, `status`, `url`, `flagged`, `source`, `first_seen_at`.
  - **`GET /api/opportunities/{id}`** → `OpportunityRow`, plus:
    - `eligibility` and `prize_or_pay`;
    - `breakdown: [{"label": str, "points": int}]` and `explanation: str`, both scored live against `ctx.holder.get()`;
    - `sightings: [{"message_id", "seen_at", "subject", "sender_name", "gmail_url"}]`.

    An unknown id gets 404.
  - **`POST /api/opportunities/{id}/{action}`**, with `action: Literal["star","unstar","dismiss","restore","applied"]`. In one transaction it updates the row and inserts `item_actions`, then publishes `ITEM_CHANGED` and returns the updated `OpportunityRow`.
    - `star` / `unstar` set `starred`.
    - `dismiss` / `applied` set `status`.
    - `restore` sets `status` to `'expired'` when the deadline is before today (HCMC), otherwise `'active'`. It undoes either dismiss or applied.
  - `sender_name` is the display name from `email.utils.parseaddr`, or the sender's domain when there is none. It is never an address.

- Produces:
  - **`class ApiServer`**, with `__init__(self, app, port: int)`:
    - `start(timeout: float = 10.0) -> int`
      - Runs `uvicorn.Server(uvicorn.Config(app, host="127.0.0.1", port=port, log_config=None, timeout_graceful_shutdown=2)).run` in a daemon thread named `"api"`.
      - Waits for `server.started` while the thread is alive.
      - Returns the bound port (`server.servers[0].sockets[0].getsockname()[1]`).
      - When the thread dies or the timeout passes, raises `ConfigError(f"Port {port} is in use (set [api] port in config.toml)")`.

    3. Prints the banner plus `API on http://127.0.0.1:<port>`.
    4. With `dev=True`, also prints `Launch password: <password>` and allows the Vite origin.
    5. Stops the server before the engine's thread on every exit path, including a failed start.
